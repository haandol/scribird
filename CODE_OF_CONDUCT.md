# Code of Conduct

## The short version

Be decent to each other. Assume the person on the other end is acting in good faith, and
argue about the code rather than about them.

## What is expected

- Keep technical disagreement technical. "This breaks the invariant because X" is useful;
  "this is obviously wrong" is not.
- Accept that a maintainer may decline a change. Scope decisions are theirs to make, and a
  rejected pull request is not a personal judgment.
- Respect the privacy rule that runs through this whole project: **never share recorded
  meeting audio or transcripts**, including in issues, pull requests, and bug reports.
  Someone else's meeting is not yours to post.

## What is not acceptable

Harassment, personal attacks, discriminatory language, sustained disruption, publishing
others' private information, or unwelcome attention of any kind. This applies in issues, pull
requests, commit messages, and any other project space.

## Reporting

If you experience or witness a problem, contact the maintainer privately — either through
[GitHub Security Advisories](https://github.com/haandol/scribird/security/advisories/new) for
anything sensitive, or by opening an issue if it can be discussed publicly. Reports are
handled confidentially.

Maintainers may remove comments, close pull requests, or block accounts for behavior that
violates this document. Being a productive contributor does not exempt anyone from it.
