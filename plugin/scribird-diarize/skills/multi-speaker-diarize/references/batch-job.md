# AWS 배치 작업 준비와 실행

세션 선택부터 `aws-<source>.json` 생성까지 필요할 때 읽는다. AWS 명령을 실행하기 전에
이 문서를 끝까지 읽는다.

## 1. 세션과 입력을 확인한다

사용자가 세션을 지정하지 않았으면 최근 목록을 보여주고 고르게 한다. 최근 세션을
임의로 선택하면 다른 회의에 비용을 쓸 수 있다.

```bash
ls -dt ~/Documents/Scribird/*/ | head -10
```

`transcript.jsonl`과 분석할 소스의 M4A가 필요하다. 기본 소스는 `remote.m4a`다.
파일이 없으면 캡처 실패 또는 저장 비활성 세션이므로 원인을 알리고 중단한다.

`me.m4a`는 대면 회의에서 같은 마이크에 여러 사람이 들어온 경우에만 추가한다. 평범한
원격 회의에서는 마이크 화자가 이미 `me`로 확정되어 있고, 추가 업로드로 얻는 이점이 없다.

## 2. 참석자, 언어, 화자 수를 정한다

분석할 소스마다 사용자가 아는 참석자 수와 이름을 묻는다. 역할·소속·자기소개 표현은
선택적 힌트다. 이름과 힌트는 로컬 매칭에만 사용하고 AWS 명령이나 업로드 파일에 넣지
않는다. 이름을 모르거나 제공하지 않아도 진행하며 결과는 `Unknown 1`부터 표시한다.

- `remote`에는 원격 참석자만 포함한다.
- 대면 회의의 `me`에는 이 기기 사용자와 같은 공간에서 마이크에 녹음된 참석자를
  포함한다.

먼저 온디바이스 전사 로케일을 확인한다.

```bash
jq -r '.locale' ~/Documents/Scribird/<세션>/transcript.jsonl | sort -u
```

- 로케일이 하나면 `--language-code`로 사용한다.
- 실제 회의에서 여러 언어를 썼다면 `--language-options`로 후보를 넘긴다.
- 언어를 알 수 없으면 언어 인자를 생략해 자동 식별을 사용한다.

화자 수 상한은 2~30이다. 참석자 수를 알면 소스별 예상 인원에 맞추고, 1명이어도 AWS
지원 범위 때문에 2를 쓴다. 모르면 기본값 5를 쓴다는 사실을 사용자에게 알린다.

## 3. AWS 조건과 데이터 경계를 설명한다

필요한 조건은 다음과 같다.

- 동작하는 AWS CLI 자격 증명과 명시된 리전
- S3 버킷 생성·공개 차단·업로드·다운로드·목록·삭제 권한
- AWS Transcribe 배치 작업 생성·조회 권한
- 회의 M4A가 선택한 AWS 계정과 리전의 S3에 임시 저장되는 것에 대한 사용자 동의

모든 분석은 S3 입력을 사용하는 배치 작업이다. 버킷이 없으면 계정·리전별 비공개 버킷을
만들고 공개 접근을 차단한다. 기본값은 결과 회수 후 실행별 객체를 삭제하는 것이다.
S3 객체를 남길 명시적 이유가 있을 때만 `--keep-s3`를 제안하고 승인 전에 알린다.

## 4. Preflight 후 승인을 받는다

`SKILL_DIR`을 실제 스킬 디렉터리의 절대 경로로 대입해 먼저 `--yes` 없이 실행한다.

```bash
/usr/bin/python3 "$SKILL_DIR/scripts/run_transcribe.py" \
  --session ~/Documents/Scribird/<세션> \
  --sources remote --language-code ko-KR --max-speakers 5
```

이 호출은 파일, AWS 자격 증명·계정·리전, 대상 소스와 용량, 버킷, 권한, 임시 저장과
정리 정책을 확인해 출력하고 exit 3으로 멈춘다. S3 쓰기나 작업 생성은 하지 않는다.

출력을 사용자에게 그대로 보여주고 다음을 명시적으로 확인받는다.

- 업로드할 소스와 용량
- AWS 계정과 리전
- S3 임시 저장과 기본 정리 정책
- 비용이 발생할 수 있는 Transcribe 배치 작업

확인받은 뒤에만 같은 명령에 `--yes`를 붙여 실행한다. 사용자가 거절하거나 조건을
준비할 수 없으면 중단한다.

결과는 세션 폴더의 `aws-<source>.json`에 저장된다. 종료 코드는 `0` 성공, `1`
AWS·파일 문제, `2` 인자 문제, `3` 승인 대기이며 exit 3은 실패가 아니다.
