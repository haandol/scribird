## 2026-07-30 — 전역 단축키 등록을 화면 생명주기에서 앱 시작 시점으로 옮긴다

- **현재 ADR**: [global-hotkey-floating-window](./0002-global-hotkey-floating-window.md)
- **변경 유형**: 동작 바꾸는 버그 수정
- **무엇이**: 단축키 등록이 메뉴바 팝오버 내용이 만들어질 때 일어났다 → 앱이 시작될 때
  일어난다. 그에 따라 "단축키는 앱이 시작된 시점부터 동작한다"를 지켜야 하는 계약으로
  본문에 명시했다.
- **왜**: 메뉴바 팝오버의 내용은 사용자가 팝오버를 처음 열 때 비로소 만들어진다. 그래서
  메뉴바 아이콘을 한 번 클릭하기 전까지 단축키가 동작하지 않았다. 이 단축키의 목적이
  화면에 도달하는 것이므로, 화면을 먼저 열어야 단축키가 준비되는 구조는 기능을
  무의미하게 만든다. 등록 실패가 아니라 등록 자체가 일어나지 않는 상태여서 기존 실패
  안내 경로로도 드러나지 않았다.
