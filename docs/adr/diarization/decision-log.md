# Decision Log: diarization

이 문서는 diarization 카테고리의 **주요 결정 변경 이력**이다. 각 ADR 본문은 현재
상태만 서술하고, "무엇이 왜 바뀌었나"의 시간축은 여기에 역순으로 쌓는다. 개별
diff 는 Git 이 보존한다.

## 2026-08-20 — 익명 화자를 발화 근거로 실제 참석자와 매칭한다

- **현재 ADR**: [s3-batch-diarization](./0001-s3-batch-diarization.md)
- **변경 유형**: 알고리즘
- **무엇이**: 익명 화자를 발화량 순서의 일반 라벨로만 표시했다 → 참석자 이름과 선택적
  힌트를 로컬에서 받고, 직접 자기소개와 고유한 1인칭 맥락으로 실제 이름을 매칭한다.
  확실한 근거나 사용자 확인이 없는 매칭은 후보로만 남기고 `Unknown N`으로 표시한다.
  이름 정보가 없거나 일부 항목이 잘못돼도 병합을 중단하지 않고 경고 후 익명 이름으로
  계속 처리한다.
- **왜**: 참석자 이름을 이미 아는 회의에서도 `Remote A/B`를 사람이 다시 해석해야 했고,
  발화량 순서는 신원 근거가 아니어서 실제 이름 목록을 그대로 대응시키면 오배정된다.
  사용 가능한 발화 근거를 활용하되 근거 없는 실명을 만들지 않는 경계가 필요하다.
- **무효가 된 것**: 발화량 순서의 일반 라벨만으로 이름 확인을 전적으로 사용자에게 맡기던
  처리 방식.
